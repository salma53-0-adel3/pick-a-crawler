# Turtle Race Game 🐢

A simple racing game I made while learning Python and the `turtle` library. 

## What it does
- Three turtles (Green, Pink, and Purple) race to the finish line.
- The game asks you to guess which turtle will win before the race starts.
- The turtles move forward at random speeds.
- When a turtle wins, it tells you if your guess was right or wrong!

## How to play
1. Run the Python script.
2. A window will pop up asking you to type a color (Green, Pink, or Purple).
3. Type your guess and press Enter.
4. Watch the race and see if you win!

## What I learned
- How to use the `turtle` module in Python.
- Using lists, loops (`for`, `while`), and functions (`def`).
- Getting user input using `textinput`.
- Generating random numbers with the `random` module.
